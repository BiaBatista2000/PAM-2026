# FeiraApp

Aplicativo desenvolvido para a Feira Tecnológica.

## 📱 Sobre o aplicativo

O FeiraApp é um aplicativo desenvolvido para facilitar o acesso às informações da Feira Tecnológica, reunindo em um único lugar informações sobre palestras, expositores, programação, mapa e outros recursos do evento.

## 🎯 Objetivo

O objetivo do aplicativo é proporcionar uma experiência simples e organizada para os visitantes da Feira Tecnológica, permitindo que encontrem rapidamente as principais informações do evento.

## 🚀 Funcionalidades

* Login de usuário
* Cadastro de usuário
* Palestras
* Expositores
* Programação
* Mapa do evento
* Favoritos
* Informações sobre a feira
* Autenticação com Firebase

## 🛠️ Tecnologias utilizadas

* Android Studio
* Kotlin
* Firebase Authentication
* XML
* Gradle
